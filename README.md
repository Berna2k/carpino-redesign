# Heladería Carpino — rediseño web

Proyecto en desarrollo para renovar la página de Heladería Carpino y practicar HTML, Sass y JavaScript con Vite.

## Funcionalidades actuales

- Diseño adaptable a pantallas pequeñas y grandes.
- Filtro de sabores por categoría.
- Menú plegable en pantallas pequeñas.
- Validación del formulario en el navegador y respuesta demostrativa. Todavía no envía mensajes.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Tecnologías

HTML, Sass, JavaScript y Vite.
